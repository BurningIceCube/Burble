# Burble

**Burble** is an open-source worldbuilding platform built around a rigorous ontology.

It is designed to support:

- Deep, consistent worldbuilding
- Story and campaign tracking
- TTRPG play
- Future live game / simulation layers

## Core Ideas

- **Ontology Layer** — What exists and what is true in the world
- **Story Layer** — Narrative structure that references the ontology
- **State Layer** — Live mechanical and situational state
- **Composites** — User-friendly facades (Culture, Economy, Ecology, etc.) over the formal ontology
