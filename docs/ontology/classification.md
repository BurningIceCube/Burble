# Classification Guide

This guide is used by both humans and AI agents to decide which formal archetype(s) an entity should receive.

## Primary Decision Tree

1. **Time-related?**
    - Span of time → Period
    - Single occurrence → Event
    - Exact moment → Instance

2. **Physical / Spatial?**
    - Has agency → Character
    - Movable as a whole → Item
    - Fixed place → Location
    - Material composition → Substance

3. **Group or Category of Being?**
    - Collective unit → Organization
    - Inherent kind of being → Species
    - Hereditary line → Lineage

4. **Capability or Standing?**
    - Something done → Action
    - Something possessed → Trait
    - Transferable social standing → Title

5. **Abstract / Structural?**
    - Interacting framework → System
    - Belief / value system → Worldview
    - Knowable information → Concept
    - Hard law of reality → Logic
    - Breakable decree/agreement → Rule

## Multi-Archetype Guidance

An entity may legitimately receive more than one archetype when it strongly satisfies multiple tests (e.g. Lineage + Organization, Item + Character).
